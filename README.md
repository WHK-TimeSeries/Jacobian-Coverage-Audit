# Supplementary Code and Source Data

This supplementary archive accompanies the manuscript *Jacobian
Coverage Audits for Reliable Neural Granger Causality in Multivariate Time Series*.

## Method and entry points

The Jacobian Coverage Audit examines whether a reported neural Granger graph
reflects the predictor's declared routes, original source coordinates, and
temporal support. The report and coverage-declaration types are implemented in
`code/src/jacobian_coverage_audit.py`; derivative and intervention utilities
are used by the study-specific experiment scripts under `code/experiments/`.
An illustrative report is in `code/paper-data/docs/phase9_stageb_manuscript/example_audit/`.
Run `reproduce.py verify` for a portable installation check; see `REPRODUCE.md`
for complete commands and the supported Stage B and Lorenz reproduction paths.
The report records declared evidence and diagnostics; it is not an automatic
causal-identifiability certificate or a one-command audit for arbitrary models.

The archive supports four parts of the submitted evidence chain:

1. controlled auxiliary-route diagnostics and fixed-target interventions;
2. raw-coordinate, partial/total, and horizon-aware Jacobian evaluation;
3. the confirmatory Stage B audit and Lorenz-96 worked example;
4. the bounded full-prefix repair and graph--prediction trade-off analysis.

It does not present legacy ISTF-Mamba or CP-depthwise filtering as a successful
graph-recovery method. Historical model classes remain in `code/src/` only
where they are required to reconstruct an audited comparator or checkpoint.

## Directory map

- `reproduce.py` / `reproduction/`: independent, hash-checked CPU validation,
  figure regeneration, and Stage B/Lorenz reproduction entry points; no Git
  checkout or original local directory is required.
- `code/`: curated model, metric, experiment, configuration, test, and release
  tooling from the final research-code lineage.
- `source_data/`: frozen CSV/JSON/TeX inputs underlying current figures and
  manuscript tables.
- `manuscript_figures/`: one independent directory per current figure,
  including plotting or Draw.io sources, data, exports, and provenance files.
- `protocols/`: Supplementary Protocol S1, the independent coordinate-preserving
  filter-control protocol, in PDF and Markdown.
- `environment/`: captured formal-run environments and fully pinned CPU and
  figure dependency locks.
- `third_party/JRNGC/`: the required metric functions, MIT license,
  and source information.
- `PROVENANCE_COMMITS.txt`: exact protocol and execution commits.
- `SCORING_PROTOCOL.md`: score objects, penalty normalization, metric conventions, archived-label
  interpretation, study-specific aggregation, and derivative-test scope.
- `PUBLICATION_SOURCE_MAP.json`: original and publication file fingerprints.
- `CHECKSUMS.txt`: file checksums used by the reproduction entry.

## Manuscript map

The manuscript PDF includes Appendices A--E. Section 4 defines the audit and
illustrates its five dimensions in Figure 2. Appendix A provides the audit record.
Controlled findings are in Section 5, and cross-domain, Lorenz-96, and
regularization results are in Section 6. Appendix D contains the historical
score-object diagnostic; Appendix E contains model settings, checkpoint
selection, window aggregation, and experimental criteria. Supplementary
Protocol S1 gives the detailed filter-control protocol for Appendix C.

## Scope of availability

NetSim and CMU Motion Capture source files are not redistributed. Their public
sources are cited in the manuscript; expected file hashes and evaluated
segments are preserved in the frozen Stage B configuration. Lorenz-96 is
generated by the included code and frozen configuration.

This archive is supplied for peer review and publisher handling. The bundled
third-party metric files retain their original MIT license and attribution;
the authors' review-use terms are in `REVIEW_USE_NOTICE.txt`.

See `REPRODUCE.md`, `THIRD_PARTY_DATA.md`, and `REVIEW_USE_NOTICE.txt` before
running the code.
