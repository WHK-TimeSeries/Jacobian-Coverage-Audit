# Third-Party Data Boundaries

The archive does not redistribute NetSim or CMU Motion Capture data.

## NetSim

Source: [Oxford FMRIB NetSim](https://www.fmrib.ox.ac.uk/datasets/netsim/).
Download `sims.tar.gz` using the simulation-data link, extract `sim3.mat`,
then run (with the CPU interpreter described in `REPRODUCE.md`):

```powershell
../kbs-cpu/Scripts/python.exe -B reproduce.py prepare-netsim --source ../downloaded/sim3.mat --output ../external-data
```

The exporter uses the original subject slicing, float64 series, transposed
binary int16 graph, and deterministic NPZ member order/metadata. It writes
only the four published Stage B subjects, and fails unless all four NPZ
checksum values equal the frozen config. No graph metric is evaluated. The
input MAT file is not assumed interchangeable with another NetSim simulation.
The retrieved `sim3.mat` checksum was
`50e42e322d0c22994d5293ce30235967b3ee5bd2e1826e65c319f6bf268bed34`;
the four exported subject files matched the frozen hashes on 2026-09-07.

## CMU motion capture

Original source: [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/).
The exact processed angle arrays used here are distributed in
[GC-xLSTM's MoCap data directory](https://github.com/harpoonix/GC-xLSTM/tree/e2064778dc11d1f6c961e517fffd127bc0bf4898/GC-xLSTM/datasets/mocap/all_asfamc).
Download `mocap_time_series_run_angles.npz` and
`mocap_time_series_salsa_angles.npz` to `../external-data/mocap/`.
The upstream commit above fixes the retrieval location; the frozen file
hashes below, not the upstream branch name, decide byte parity.
Both downloads from that fixed upstream commit were checked against the
frozen hashes on 2026-09-07.

| Relative path | checksum |
| --- | --- |
| mocap/mocap_time_series_run_angles.npz | cc180d486832fbeb08a7be8de69494dccdc31615e0155022c96aef674fe17569 |
| mocap/mocap_time_series_salsa_angles.npz | 9f368e638d2c22327d8b67901c6eaab1a46ee44b249dc88faa49f220ab28dd39 |

These are processed inputs, not raw ASF/AMC files. Raw-data download alone
does not establish parity. Respect the respective providers' data terms;
the project does not relicense or redistribute either dataset in this ZIP.

## Frozen input validation

The frozen Stage B configuration at
`code/configs/phase9_audit_stageb_v1.json` records, for every evaluated file:

- its expected relative path;
- checksum digest;
- evaluated segment boundaries; and
- the preprocessing/evaluation policy.

The manuscript cites the corresponding public sources. Users who independently
obtain those datasets must verify the hashes before treating a rerun as a
reconstruction of the reported audit.

Synthetic VAR and Lorenz-96 inputs are generated by the included code. Frozen
aggregate summaries and plot-ready source tables are included under
`source_data/` and `manuscript_figures/*/data/`.
